# Vigie pour Mac

Installateurs et mises à jour de Vigie, application locale de comptabilité associative.

[Télécharger Vigie pour Mac](https://github.com/AloisGoeury/Vigie-Releases/releases/latest/download/Vigie.dmg)

Le même installateur fonctionne sur Mac Intel et Apple Silicon.

1. Ouvrir le DMG et glisser Vigie dans Applications.
2. Éjecter le disque, puis ouvrir Vigie depuis Applications.
3. Cette version n’est pas notariée par Apple. Si macOS bloque la première ouverture, utiliser Réglages Système → Confidentialité et sécurité → Ouvrir quand même, si proposé, après la tentative de lancement. Ne pas désactiver globalement les protections du Mac.

Pour les nouvelles versions : Paramétrage → Mises à jour → Rechercher une mise à jour, puis Mettre à jour et redémarrer. Terminer les saisies avant de continuer.

Les comptes restent sur votre ordinateur. Aucun compte GitHub n’est nécessaire pour télécharger ou mettre à jour Vigie. Faire régulièrement une sauvegarde depuis Paramétrage → Sauvegarde.

Ce dépôt contient uniquement les fichiers de distribution et leurs informations de version, sans code source ni données comptables.
